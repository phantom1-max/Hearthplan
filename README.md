# Hearthplan

A responsive house-planning web app for creating editable 2D floor plans and viewing an isometric 3D concept. Includes room editing, measurement units, local autosave, themes, and PNG/SVG export.

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build`.

> Concept planning tool only. Have a qualified local architect verify structural and building-code requirements before construction.
